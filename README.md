# Agent Clinic — מרפאת תחזוקה לסוכני תוכנה

Agent Clinic היא אפליקציה מקומית לניהול מצבם של סוכני תוכנה: לרשום סוכן, לתעד תקלה שפגעה בו, לעקוב אחר חומרה ומצב, ולשמור את הטיפול ואת התוצאה. זהו כלי תחזוקה לתוכנה — לא כלי רפואי ולא מערכת לאבחון בני אדם.

## חזון והיקף

- ממשק Web בעברית מלאה ובכיוון ימין־לשמאל.
- Dashboard נוח להצגת תמונת מצב של הסוכנים והבעיות הפתוחות.
- SQLite לאחסון מקומי, ללא תלות בשירות ענן.
- ללא CDN, תמונות מרוחקות, טלמטריה או קריאות חוץ בזמן הריצה; הדבר מיועד גם לסביבת רשת מסוננת.
- נתוני דוגמה פיקטיביים לצורך בדיקה והדגמה.

הפרויקט נמצא בתחילת הקורס. בשלב הנוכחי קיימת סביבת TypeScript בסיסית בלבד; ממשק, API ויכולות הניהול יתווספו לפי המפרטים שבתיקיית `specs/`.

## סביבת פיתוח נוכחית

- Node.js ‏25.2.1
- npm ‏11.6.2
- TypeScript ‏5.9.3
- מצב TypeScript Strict

## התקנה והרצה

מתיקיית הפרויקט:

```powershell
npm ci
npm run build
npm start
```

בשלד הנוכחי `npm start` מדפיס הודעת מוכנות. שרת Hono והאפליקציה עצמה יוגדרו בשלבי הפיתוח הבאים; הוראות ההרצה יעודכנו כאשר השרת יהיה זמין.

## מסמכי הפרויקט

- `TASKS.md` — לוח התקדמות הקורס, תוצאות בדיקה, החלטות וחסימות.
- `specs/mission.md` — מטרת המערכת והגבולות שלה.
- `specs/techstack.md` — טכנולוגיות וכללי פיתוח.
- `specs/roadmap.md` — שלבי המימוש של ה־MVP.

## בדיקות

כרגע ניתן לאמת את שלד TypeScript באמצעות `npm run build`. בדיקות אוטומטיות ליכולות המוצר יתווספו כחלק מתכנון ומימוש הפיצ'רים, ויתועדו ב־`TASKS.md`.
