# מפרט פיצ'ר — לוח התקדמות הקורס

**סטטוס:** תועד ונבדק מקומית לאחר המימוש<br>
**מסלול:** כלי עזר מקומי לסביבת הפרויקט, מחוץ לתחום הנתונים של המרפאה<br>
**מקור דרישה:** בקשת המשתמשת להציג את התקדמות מטלות הקורס גם בתוך האפליקציה.

## 1. מטרה והיקף

להציג עמוד עברי ונגיש שמסכם את מטלות הקורס מתוך `TASKS.md`, כדי שמצב ההתקדמות יהיה גלוי באפליקציה בלי לנהל מקור נתונים כפול. העמוד אינו משנה את קובץ המשימות, את נתוני SQLite או את ה־Roadmap של המוצר.

## 2. דרישות פונקציונליות

| מזהה | דרישה |
|---|---|
| FR-1 | `GET /course` יציג עמוד HTML בעברית עם `lang="he"` ו־`dir="rtl"`. |
| FR-2 | הנתונים יחושבו מחדש מתוך תיבות הסימון ב־`TASKS.md` בכל בקשה; רק משימות בשלבים 1–8 (עד MVP, כולל) ייכללו בספירת החובה. |
| FR-3 | העמוד יציג את מספר המשימות שהושלמו ואת הסך הכולל. |
| FR-4 | העמוד יציג התקדמות לכל שלב, לרבות מספר משימות שהושלמו וסרגל התקדמות נגיש. |
| FR-5 | העמוד יציג בנפרד משימות המסומנות כחסומות או כממתינות לאישור. |
| FR-6 | העמוד הוא לקריאה בלבד; אין לו מסלול או פעולה שמשנים את `TASKS.md`. |
| FR-7 | כל סגנונות העיצוב יוגשו מקובצי הפרויקט המקומיים; אין שימוש ב־CDN או בשירות חיצוני. |

## 3. דרישות ממשק ותאימות

- להוסיף קישור ניווט בעברית לעמוד הקורס, בלי להחליף את Dashboard המרפאה.
- לשמור על מבנה HTML סמנטי, Labels ברורים ו־`<progress>` נגיש.
- לתמוך במסכי 320px,‏ 375px ו־1280px ללא גלילה אופקית של העמוד.
- להציג מצב שגיאה גלוי ומתועד ביומן השרת אם לא ניתן לקרוא את קובץ המשימות; אין להציג נתונים חלופיים כאילו הצליחו.

## 4. מחוץ להיקף והחלטות

- אין להציג את משימות הקורס כחלק מספירות הסוכנים והתקלות.
- שיעורים והרחבות אחרי שלב 8 אינם נכנסים לסכום או לסרגל ההתקדמות של השלמת הקורס.
- אין להעתיק משימות למסד SQLite או לתחזק קובץ התקדמות נוסף.
- העמוד מיועד להרצה מתיקיית הפרויקט, כמתועד ב־README.
- ההחלטה להשתמש בנתיב נפרד `/course` שומרת על אחריות מוצרית ברורה: `/` נשאר Dashboard של Agent Clinic.

## 5. תוכנית עבודה

1. לפרש כותרות `## שלב N` ותיבות סימון של Markdown לטיפוסי התקדמות.
2. לחשב סיכום כללי, סיכום לכל שלב, חסימות ואישורים.
3. ליצור תצוגת RTL רספונסיבית ולהוסיף קישור ניווט.
4. להוסיף בדיקות לפענוח, לספירה, למסלול HTTP, לשפה ול־CSS.
5. לבדוק ב־HTTP ובדפדפן ברוחבי מסך צרים ורחבים.

## 6. תנאי הצלחה ו־Validation

- `npm test` משלים TypeScript Build וכל הבדיקות ללא כשל.
- `GET /course` מחזיר `200` ותוכן בעברית וב־RTL.
- מספר השלבים וסיכום התקדמות נגזרים מ־`TASKS.md`, לא ממספרים קשיחים.
- פענוח מתעלם מתיבות סימון בפרקים שמחוץ לשלבי הקורס.
- פענוח אינו סופר משימות בשלב 9 ואילך, גם כאשר הן מופיעות ב־`TASKS.md`.
- אין שינוי בקובץ המשימות בעקבות צפייה בעמוד.
- בדיקה בדפדפן ב־320px,‏ 375px ו־1280px מאשרת שאין גלילה אופקית או שגיאות Console.
