# תוכנית — Hello Hono

**הערת תהליך:** זהו פירוק עבודה שנוסח בבדיקת 2026-11-14 מתוך הקוד והמסמכים הקיימים. היסטוריית Git אינה מוכיחה את מועד כתיבת התכנון המקורי או את סדר המימוש.

## קבוצת משימות 1 — בסיס Hono

1. לנעול תלויות ולוודא TypeScript Strict ו־NodeNext.
2. לייצא אפליקציית Hono שניתנת לבדיקה בלי לפתוח פורט.
3. להגדיר ולבדוק את `GET /api/hello` ואת תגובות הנתיבים הלא מוגדרים.
4. להפעיל את שרת Node על loopback ולדווח על כשלי הפעלה.

## קבוצת משימות 2 — Layout ועיצוב

1. לממש Header, Main ו־Footer בקבצים נפרדים.
2. להרכיב אותם דרך Layout משותף לכל מסכי ה־HTML.
3. לקשר CSS מקומי ולוודא עברית, RTL ופריסה רספונסיבית.

## קבוצת משימות 3 — אימות

1. להריץ `npm run build` ו־`npm test` באמצעות Vitest.
2. לאמת את API ואת נתיב 404 בבדיקות ובבקשת HTTP מקומית.
3. לבדוק את מסכי המוצר ברוחבי תצוגה צרים ולוודא שאין גלישת עמוד.
4. לסנכרן את המפרט, ה־README ולוח המשימות רק עם תוצאות שנצפו.
