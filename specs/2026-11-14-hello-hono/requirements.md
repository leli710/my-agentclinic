**תאריך ניסוח:** 2026-11-14<br>
**סטטוס:** נרמול רטרוספקטיבי לצורך אימות; אין לראות במסמך זה הוכחה שהיה קיים לפני המימוש.<br>
**מפרט מפורט:** [specs/features/hello-hono.md](../features/hello-hono.md)

## מטרה והיקף

לאמת שרת Hono מקומי ב־TypeScript Strict ולשמור על API דוגמה קטן ויציב. הפיצ'ר כולל Layout עברי משותף, רכיבי Header/Main/Footer עצמאיים, CSS מקומי ופריסה רספונסיבית. דף הבית הנוכחי הוא Dashboard המוצר; תוכנו אינו חלק מחוזה ה־API.

## דרישות פונקציונליות

1. `GET /api/hello` מחזיר `200`, כותרת `application/json` וגוף מדויק `{"message":"Hello Hono!"}`.
2. נתיב לא מוגדר ושיטת HTTP לא נתמכת אינם מחזירים הצלחה.
3. השרת מאזין רק ב־`127.0.0.1:3000`; כשל בהפעלה מדווח במפורש.
4. כל דפי ה־HTML מרכיבים Layout משותף עם Header, Main ו־Footer סמנטיים, כאשר כל רכיב נמצא בקובץ משלו.
5. המסמך מוגדר `lang="he"` ו־`dir="rtl"` ומגיש CSS מקומי ללא CDN.
6. מסכים צרים אינם יוצרים גלילה אופקית של כל העמוד.

## אילוצים

- Hono על Node.js, TypeScript במצב Strict ו־ES Modules/NodeNext.
- Vitest הוא מריץ הבדיקות; `npm test` מריץ Build ולאחריו את הבדיקות.
- SQLite, CRUD של סוכנים/תקלות ושירותים חיצוניים מחוץ להיקף הפיצ'ר.
