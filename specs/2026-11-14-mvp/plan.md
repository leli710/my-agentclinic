# תוכנית — Agent Clinic MVP

**הערת תהליך:** זהו פירוק עבודה שנוסח בבדיקת 2026-11-14 מתוך הקוד, המפרטים וה־Roadmap הקיימים. הוא אינו הוכחה לתכנון המקורי לפני המימוש.

## קבוצת משימות 1 — אימות היקף

1. להשוות את mission, techstack, roadmap ומפרטי Agents and Ailments.
2. להגדיר את דרישות ה־MVP ואת גבולות ההרחבות.

## קבוצת משימות 2 — מימוש מוצר

1. להשלים Dashboard וסיכומים מבוססי SQLite.
2. להשלים זרימות סוכנים, תקלות, טיפול ותוצאה.
3. להשלים Layout משותף, RTL, הודעות שגיאה ופריסה רספונסיבית.
4. לשמור על התקנה מקומית וללא נכסים או שירותים מרוחקים.

## קבוצת משימות 3 — איכות ואימות

1. להריץ התקנת npm נקייה באופן בטוח, TypeScript Build ו־Vitest.
2. לבדוק API, persistence, migration, seed ונתיבי שגיאה.
3. לבדוק תצוגות בדפדפן ברוחבים צרים ורחבים.
4. להשוות תוצאות לכל דרישה, לעדכן Roadmap/TASKS/README/CHANGELOG.
5. לתעד בנפרד פערי היסטוריית Git שאי אפשר לשחזר בלי להמציא ראיות.
