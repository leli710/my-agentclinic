# דרישות — Agent Clinic MVP

**תאריך ניסוח:** 2026-11-14<br>
**סטטוס:** נרמול רטרוספקטיבי לצורך אימות; אין לראות במסמך זה הוכחה שהיה קיים לפני המימוש.<br>
**מקורות:** [מטרת המוצר](../mission.md), [מפת הדרכים](../roadmap.md), [Agents and Ailments](../features/agents-and-ailments.md), [Hello Hono](../features/hello-hono.md).

## מטרה

לספק חתך עובד של Agent Clinic: Dashboard ותיעוד מקומי של סוכני תוכנה ותקלותיהם, ללא הפעלת סוכנים או תלות בשירותים חיצוניים.

## דרישות MVP

1. האפליקציה עולה ב־`127.0.0.1:3000` ומגישה Dashboard ונתיב Hello Hono.
2. אפשר לנהל סוכנים ותקלות, לקשר ביניהם, לתעד חומרה, מצב, טיפול ותוצאה.
3. SQLite שומר את הנתונים ומפעיל מיגרציות; נתוני דוגמה פיקטיביים נוספים למסד חדש בלבד.
4. Dashboard וסיכומים תואמים לנתוני המסד.
5. קלט לא תקין, מזהים לא קיימים ונתיבים לא מוגדרים אינם מוצגים כהצלחה.
6. המסכים בעברית וב־RTL, מבוססי Layout משותף, רספונסיביים ומגישים CSS מקומי.
7. בדיקות אוטומטיות מכסות את מסלולי המוצר העיקריים, הוולידציה, ה־SQLite וה־HTML.

## מחוץ להיקף

חשבונות, פריסה ציבורית, הפעלה או תזמור של סוכני AI, APIs חיצוניים, סנכרון ענן, אבחון רפואי אנושי ותכונות קורס שמוגדרות כהרחבות לאחר MVP. עמוד `/course` הוא תוספת מקומית נפרדת ואינו חלק מציון יכולות המרפאה.
