# תוכנית — Agents and Ailments

**הערת תהליך:** זהו פירוק עבודה שנוסח בבדיקת 2026-11-14 מתוך הקוד והמסמכים הקיימים. היסטוריית Git אינה מוכיחה את מועד כתיבת התכנון המקורי או את סדר המימוש.

## קבוצת משימות 1 — מודל ומסד נתונים

1. להגדיר טיפוסי Domain וכללי ולידציה.
2. ליצור Migration עם אילוצים, foreign key ואינדקסים.
3. לממש פתיחת SQLite, runner למיגרציות, שאילתות ונתוני דוגמה אידמפוטנטיים.

## קבוצת משימות 2 — נתיבים וזרימות

1. לממש CRUD לסוכנים ומעבר בין פעיל למושבת.
2. לממש יצירה, עדכון, סינון ופרטי תקלות.
3. לאמת שגיאות, מזהים וקישור לסוכן פעיל; לשמור על Post/Redirect/Get.

## קבוצת משימות 3 — תצוגה

1. ליצור Dashboard, רשימות ועמודי פרטים בעברית וב־RTL.
2. להרכיב Layout משותף מרכיבי Header/Main/Footer נפרדים.
3. להוסיף טפסים, מצבי שגיאה/ריק, Pico CSS מקומי ו־CSS רספונסיבי.
4. להגדיר Props לתצוגות מחוץ לקובץ הרינדור.

## קבוצת משימות 4 — אימות

1. לכתוב בדיקות Vitest ל־Migration/seed, persistence, ולידציה וזרימות HTTP.
2. להריץ Build ובדיקות; לתקן רק פערים מול המפרט.
3. לבדוק מסכים, קונסול ורוחבים צרים בדפדפן.
4. לעדכן Roadmap, TASKS ו־CHANGELOG על בסיס תוצאות מאומתות.
