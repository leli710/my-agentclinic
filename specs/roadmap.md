# מפת דרכים — Agent Clinic

ה־Roadmap מתאר חתכים קטנים שניתן לממש, לבדוק ולסקור בנפרד. המצב מסומן כהושלם רק לאחר אימות מול הקוד והבדיקות; היסטוריית Git מתועדת בנפרד ב־`TASKS.md`.

## מצב אימות — 2026-11-14

- שלב 0 — הושלם; שני commits בסיסיים קיימים.
- שלב 1 — המימוש והקריטריונים אומתו מחדש; Build, Vitest, HTTP, Layout ו־RTL עברו.
- שלב 2 — CRUD, מיגרציה, seed, ולידציה, escaping וזרימות בדפדפן אומתו.
- שלב 3 — Dashboard וזרימות MVP אומתו; `/course` אינו כולל שיעורים אחרי MVP בספירת החובה.
- שלב 4 — `npm ci`, בדיקות, HTTP ובדיקת דפדפן עברו.
- הסתייגות: היסטוריית Git אינה מוכיחה שה־Feature Specs קדמו למימוש או שנוצרו ענפי Agents/MVP והתקיימו מיזוגים. המסמכים המובנים שנוספו לצורך האימות מסומנים כרטרוספקטיביים.

## שלב 0 — בסיס ו־Constitution

- שלד TypeScript Strict, Git ו־npm עם Lockfile.
- הגדרת מטרה וקהל יעד, טכנולוגיות, עקרונות וגבולות מוצר.
- תנאי יציאה: Build נקי ו־Mission/Techstack/Roadmap עקביים.

## שלב 1 — Hello Hono

- שרת Hono מקומי ו־`GET /api/hello` עם חוזה JSON מוגדר.
- Layout משותף בעברית עם Header, Main ו־Footer בקבצים נפרדים.
- CSS מקומי, RTL ותמיכה במסכים צרים.
- תנאי יציאה: Build, בדיקות Vitest ו־HTTP מאשרים את החוזה, ה־Layout ו־404.

## שלב 2 — Agents and Ailments

- מודל סוכנים/תקלות, SQLite ומיגרציות עם constraints ו־foreign keys.
- יצירה, הצגה, עדכון והשבתת סוכנים; פתיחה, סינון ועדכון של תקלות וטיפולים.
- ולידציה בצד השרת, שגיאות ברורות, Props מטופסים ונתוני דוגמה פיקטיביים.
- תנאי יציאה: זרימות הנתונים, המיגרציה וה־seed נבדקים אוטומטית.

## שלב 3 — MVP

- Dashboard שמציג סיכומים שתואמים למסד.
- מסכי מרפאה בעברית, RTL, נגישות בסיסית ופריסה רספונסיבית.
- אין תלות בנכסים מרוחקים או בשירותים חיצוניים בזמן ריצה.
- תנאי יציאה: מסלולי המוצר העיקריים עובדים ונבדקים ב־API ובדפדפן.

## שלב 4 — אימות וייצוב מקומי

- Build, בדיקות Vitest, בדיקת HTTP, בדיקת מיגרציות ו־`npm ci`.
- אימות תיעוד מול הקוד; עדכון Roadmap,‏ TASKS ו־CHANGELOG רק לאחר תוצאה נצפית.
- תנאי יציאה: אין פערים ידועים בדרישות המוצר; פערי תהליך היסטוריים מדווחים בנפרד ולא משוחזרים באופן מלאכותי.

## מחוץ להיקף המוצר

עמוד `/course` הוא כלי עזר מקומי נפרד. Skills, Context7, GitHub Spec Kit, OpenSpec, ACP ופרויקט Legacy הם הרחבות קורס ואינם תנאי להשלמת MVP המרפאה.
