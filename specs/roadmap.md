# מפת דרכים — Agent Clinic

## סדרי עדיפויות

ה־Roadmap מתאר את ה־MVP של המוצר ואת סדר המימוש שלו. משימות הרחבה של הקורס (כגון GitHub Spec Kit, OpenSpec או Portability) מנוהלות ב־`TASKS.md` ואינן מרחיבות את היקף המוצר.

### P0 — בסיס הפרויקט ו־Constitution

- שלד TypeScript עם Strict Mode, npm lockfile ו־Git.
- הגדרת מטרה, גבולות מוצר, טכנולוגיות ומבנה פרויקט.
- קריטריון יציאה: Build נקי, מסמכים עקביים, והיקף MVP מוסכם.

### P1 — Hello Hono

- כתיבת Feature Spec לפני המימוש.
- הרמת שרת Hono מקומי ונתיב בדיקה/בריאות מינימלי.
- אימות הרצה בפועל ותיעוד פקודת הפעלה.
- קריטריון יציאה: השרת עולה מקומית והנתיב שהוגדר במפרט מחזיר תגובה צפויה.

### P1 — Agents and Ailments

- מפרט מלא לפני מימוש.
- מודל סוכנים ותקלות, מסד SQLite ומיגרציות SQL.
- מסכי ניהול בסיסיים, טפסי קלט ו־Pico CSS מקומי.
- רישום טיפול ותוצאה, עם נתוני דוגמה פיקטיביים.
- קריטריון יציאה: תרחיש יצירה, שיוך, טיפול וצפייה חוזרת עובד מול SQLite.

### P1 — Dashboard והשלמת MVP

- תצוגת מצב בעברית וב־RTL לסוכנים, חומרה ותקלות פתוחות.
- עדכון, סינון ומצבי ריק/שגיאה.
- התאמה למסכים צרים, ללא תלות בנכסים מרוחקים.
- קריטריון יציאה: כל זרימות ה־MVP עובדות בדפדפן ומתאימות למפרט המאושר.

### P1 — Validation ושחרור מקומי

- הוספת מדיניות בדיקות אוטומטיות ועדכון ה־Roadmap.
- בדיקות API, persistence, ולידציה ותצוגות; טיפול בכשלים.
- בדיקת התקנה נקייה, migrations ונתוני דוגמה.
- קריטריון יציאה: Build ובדיקות עוברים; אין פערים ידועים בין Spec למימוש.

## משימות קורס שאינן חלק מה־Roadmap של המוצר

Skills, Context7, GitHub Spec Kit, OpenSpec, ACP/Agents נוספים, CHANGELOG ופרויקט Legacy מתועדים ומנוהלים בלוח `TASKS.md`. הם אינם תנאי להרחבת המוצר מעבר לדרישות ה־MVP.
