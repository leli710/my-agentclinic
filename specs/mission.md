# משימה וגבולות מוצר — Agent Clinic

## מטרת המערכת

Agent Clinic היא “מרפאה” מקומית לתחזוקה של סוכני תוכנה. היא עוזרת למפתחים ולמתחזקי מערכות לנהל רישום של סוכנים, לתעד תקלות או סימני כשל המשפיעים עליהם, לתעד טיפול ותוצאה, ולראות במבט אחד אילו סוכנים זקוקים לתשומת לב.

המונחים “מרפאה”, “מחלה” ו“טיפול” הם מטאפורה לתחזוקת תוכנה בלבד. המערכת אינה מיועדת לאנשים, אינה שומרת מידע רפואי ואינה מספקת ייעוץ רפואי.

## משתמשים ותרחיש עיקרי

המשתמשת היא מפתחת או מתחזקת שמפעילה סוכני תוכנה ורוצה מקום פשוט ומסודר לתעד את מצבם ואת הטיפול בתקלות. התרחיש המרכזי:

1. מוסיפים סוכן עם שם ותיאור קצר.
2. פותחים עבורו רשומת תקלה, מתעדים תיאור, חומרה ומצב.
3. מתעדים את פעולת הטיפול ואת תוצאתה.
4. חוזרים ל־Dashboard כדי לזהות תקלות פתוחות וסוכנים שדורשים תשומת לב.

## יכולות ה־MVP

- הצגת Dashboard בעברית וב־RTL עם סיכום סוכנים ותקלות.
- יצירה, צפייה, עדכון והשבתה של רשומות סוכנים.
- יצירה, צפייה ועדכון של תקלות ושיוכן לסוכן.
- סיווג חומרה ומצב, סינון תקלות פתוחות ומעקב אחר פתרון.
- רישום טיפול ותוצאה עבור תקלה.
- נתוני דוגמה פיקטיביים להצגה ולבדיקה.
- שמירת המידע במסד SQLite מקומי.
- הצגת שגיאות קלט ותקלות פעולה באופן ברור, ללא הצגת הצלחה כוזבת.

הפרטים המדויקים של שדות, מצבי עבודה ונתיבי API ייקבעו במפרטי הפיצ'רים לפני המימוש.

## עקרונות מוצר

1. **מקומי כברירת מחדל:** המידע נשמר במחשב שבו רץ השרת.
2. **פשטות לפני אוטומציה:** ה־MVP מתעד תקלות וטיפולים; הוא אינו מפעיל סוכנים ואינו מבצע שינוי אוטומטי במערכות חיצוניות.
3. **ברור ולא מטעה:** השפה הרפואית נשארת מטאפורה גלויה, וכל הודעת שגיאה מתארת את הבעיה ואת הפעולה שנכשלה.
4. **עברית נגישה:** תוויות, פעולות ומידע למשתמש מוצגים בעברית, עם פריסת RTL.
5. **רשת מינימלית:** בזמן הריצה אין צורך בשירותי ענן, CDN או שליחת נתונים החוצה.
6. **נתוני הדגמה בטוחים:** נתוני הדוגמה מומצאים ואינם מייצגים אנשים או מערכות אמיתיות.

## מחוץ להיקף ה־MVP

- אבחון, טיפול או ניהול של מצב רפואי אנושי.
- הפעלת סוכני AI, תזמור שלהם או גישה למפתחות/API חיצוניים.
- הרשמה, חשבונות משתמשים, הרשאות רב־משתמשיות או פריסה ציבורית.
- סנכרון ענן, טלמטריה, אינטגרציות חיצוניות או שימוש בנכסי CDN.
- המלצות אוטומטיות שנוצרות על ידי מודל.

אפשר לשקול רעיונות נוספים רק לאחר שהיקף ה־MVP יושלם, ובנפרד ממסלול החובה של הקורס.
